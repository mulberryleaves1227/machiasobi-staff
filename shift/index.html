#02 撮影禁止対応（撮禁A・B交代制）
藍場浜・新町橋東公園・西公園
🔁 A/B交代制のルール▼
  • Aの番：A が撮影禁止札を持って巡回、B は待機・休憩
  • Bの番：B が A の代わりに担当、A は休憩
  • 交代タイミングはシフト表またはリーダーの指示に従う
📋 声かけの流れ▼
  1. 来場者から見える位置に撮禁札・表示を出す
  2. スマホ・カメラを構えている人に落ち着いて声かけ
  3. それでも続ける場合 → リーダー・八木・桑野へ共有
「大変恐れ入りますが、こちらのエリアでは撮影はご遠慮いただいております」

「撮影禁止となっておりますので、カメラのご使用はお控えください」
📍 確認すべき場所▼
  • ステージ正面・横・後方
  • 橋の上・対岸・歩道側（撮禁と知らない人がいる）
  • 観覧者の列の中・後方
🚫 絶対にやってはいけないこと▼
  • 来場者のスマートフォン・カメラに触る
  • 撮影データの削除を個人判断で求める
  • SNS投稿の削除を個人判断で求める
  • 強い口調で注意する・来場者と口論する
📸 撮影OKの例外▼
演者が「撮影OK」と言ったら、撮影禁止札を下げ、八木・桑野にLINEで報告。
⚠️ 30分以上同じ場所に立つこともあります。自分の体調も確認してください。

  • 体調不良者を日陰へ案内してリーダーへ連絡
  • チラシの配布
❌ リーダー・本部に確認が必要なこと▼
  • 入場可否の判断
  • 整理券・優先入場・再入場ルールの判断
  • 物販ルールや購入制限の判断
  • ステージ開始・終了・変更情報の案内
  • 撮影可否が不明な場合の判断
  • クレーム・迷子・怪我・救急対応
  • 警察・消防・救急への連絡が必要な事案
🛍️ 物販・整理券の問い合わせ▼
ボランティアスタッフ側では詳細を把握していません。各物販・出展メーカーの公式SNSや現地掲示を案内する。
✕「たぶん買えます」「並べば大丈夫です」「まだありそう」は絶対に言わない！
#15 アンケート調査
QRコードから回答してもらう／目標は1000件
🎯 この業務の目的▼
次回以降の開催・運営改善につなげる重要な業務。回答者が特定の場所・時間・客層に偏りすぎないよう複数エリアを巡回する。
📋 基本の流れ▼
  1. アンケートQRコードのポスター等を身につけて巡回
  2. 来場者にアンケート協力をお願いする
  3. QRコードを読み取ってもらう
  4. スマートフォンでアンケートに回答してもらう
  5. 回答後、スダチの受け取り場所を案内する
  6. 袋入りのスダチは東公園テントか藍場浜テントで受け取り
⚠️ 注意点▼
  • 無理に引き止めない
  • 回答を急かさない
  • 来場者のスマートフォンを勝手に操作しない
  • 回答内容をのぞき込まない
  • 記念品の在庫・配布条件を推測で案内しない
スダチの在庫は八木・桑野へ確認。袋詰め作業の方法・担当は調整中です。
#16 ごみ収集・美化
分別をしっかり。竹串・割り箸は怪我に注意
🗑️ ごみの分別区分▼
区分例
燃えるごみ紙くず、食品容器、プラスチック類
燃えないごみ不燃物など
カン・ビン・ペットボトル飲み残しは中身を捨ててから
⚠️ 竹串は怪我につながる可能性があります。放置を見つけたら注意し、直接手で拾う場合は慎重に！
👀 巡回のポイント▼
  • 飲食エリア・キッチンカー周辺を重点的に確認
  • ごみ袋がいっぱいになったら、すぐに交換し、ごみは集積所へ
  • 飲み残し飲料は中身を捨ててから分別
  • 放置された荷物と見まがうごみは、判断に迷ったら本部へ確認
🎒 道具の場所▼
ゴミ袋、軍手、火ばさみなどはボランティアテントにあります。
#17 引継ぎ手順（SBAR）
状況・経緯・対応中・次の担当へのお願いを伝える
📋 引継ぎで伝える4つの項目▼
引継ぎは担当を「つなぐ」作業。情報が途切れると、次の担当者が一から状況を把握し直すことになります。

S状況：今の場所・担当・何が起きているか
B経緯：さっきまで何をしていたか・特記事項
A対応中：今対応していること・途中まで案内したこと
R依頼：次の担当者に引き続き対応してほしいこと
💬 引継ぎ例▼
「藍場浜東側で撮禁Aを担当していました。今は特に問題なし。14時のステージ前から来場者が増えはじめていて、後方の通路が少し詰まりはじめています。引き続き後方を意識してください」
⚠️ 引継ぎの注意点▼
  • 「あとはよろしく」だけで終わらない
  • 担当が重なる時間を作る（数分の並走でOK）
  • 持ち物の受け渡しを忘れない（撮禁札・ごみ袋等）
  • 休憩から戻ったらまず状況確認
#18 迷子・落とし物対応
窓口は藍場浜テント・東公園ボランティアテント
🧒 迷子・同行者不明の場合▼
  1. 本人に落ち着いて声をかけ、安全な場所へ案内する
  2. 名前・年齢・一緒にいた人の特徴を聞く
  3. 藍場浜テント または 東公園ボランティアテントへ連れて行く
  4. 自分一人で解決しようとしない → 必ずテントへ
👛 落とし物・貴重品の場合▼
  1. 拾った・見つけた場合は、その場で勝手に開けない
  2. 藍場浜テント または 東公園ボランティアテントへ持参
  3. スマートフォン・財布・身分証は特に速やかに持参
  4. 「拾いました。〇〇付近で見つけました」と伝える
⚠️ 落とし物を自分で保管しない。必ずテントへ持参して担当者に引き渡す。
#19 救護・緊急時対応
まず共有・相談・報告。医療判断はしない
✅ ボランティアスタッフがやること▼
  • 体調不良者・怪我人・危険な状況をすぐにリーダー・八木・桑野へ共有
  • 必要に応じて、本人を日陰・安全な場所へ案内
  • 周囲の通路を確保し、人だかりを作らないよう声かけ
  • リーダー等から指示があればその指示に従って誘導補助
🚫 ボランティアスタッフが判断しないこと▼
  • イベントの中止・再開判断
  • 避難開始・避難経路の最終判断
  • 救急車を呼ぶかどうかの判断
  • 医療判断・応急処置の要否判断
  • AED設置場所を自己判断で案内すること
📞 内容別の対応先▼
体調不良・怪我・熱中症疑い藍場浜テント / 東公園ボランティアテント
救急判断が必要そうな場合八木・桑野へ相談・報告
AED設置場所・救護所・避難場所・警備配置・関係機関連絡先 → 八木・桑野に指示を確認
#20 待機中にできること
待機中も、周囲の安全や困っている人を確認する
👀 待機中のチェックポイント▼
  • 周辺の通路・人だまり状況を確認する
  • 近くの来場者が困っていないか確認する
  • ごみ・落とし物・危険物がないか確認する
  • 体調不良者・倒れている人がいないか確認する
  • 「なんか詰まりそう」という違和感を拾う
📡 リーダーへの報告のコツ▼
【場所】〇〇エリア 【状況】〇〇が△△になっています 【対応】今〇〇しています 【相談】〇〇の判断をお願いします
🔋 体調管理も大切な業務のひとつ▼
  • 定期的に水分補給をする
  • 日なたで長時間立ち続けない
  • 体調が悪いときはすぐにリーダーへ申告する
スタッフが倒れると、そのエリアの対応が手薄になります。自分の体調管理も会場運営の一部！
